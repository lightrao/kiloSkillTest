# Kilo Code Skill Test Project

This project is a workspace for testing and demonstrating [Kilo Code Agent Skills](https://kilo.ai/docs/features/skills). It includes a variety of specialized skills designed to extend the capabilities of AI agents with domain-specific knowledge and workflows.

## 🚀 Project Overview

The project is organized to showcase the power of Agent Skills across different domains, from algorithmic art to financial modeling.

## 📁 Structure

- `.kilocode/skills/`: Contains the collection of Agent Skills.
- `calculator.py`: A simple calculator utility script.
- `hello.py`: A greeting script.
- `star.py`: A script for generating star patterns.

## 🛡️ Included Agent Skills

The project features a robust set of skills located in `.kilocode/skills/`:

- **algorithmic-art**: Creating generative art using p5.js.
- **brand-guidelines**: Applying official brand styling.
- **canvas-design**: Advanced visual art and document design.
- **doc-coauthoring**: Structured workflow for collaborative writing.
- **docx**: Professional Microsoft Word document manipulation.
- **frontend-design**: High-quality UI/UX design and implementation.
- **internal-comms**: Standardized corporate communication templates.
- **mcp-builder**: Guide for creating Model Context Protocol servers.
- **pdf**: Comprehensive PDF processing (merging, splitting, OCR).
- **pptx**: Professional presentation creation and editing.
- **project-conventions**: Standards for code documentation.
- **quarto-pptx-creator**: Creating presentations via Quarto and Revealjs.
- **skill-creator**: A meta-skill for building new Agent Skills.
- **slack-gif-creator**: Optimizing animated GIFs for Slack.
- **theme-factory**: Styling artifacts with pre-set themes.
- **web-artifacts-builder**: Building complex, multi-component React artifacts.
- **webapp-testing**: Automated testing using Playwright.
- **xlsx**: Financial modeling and advanced Excel operations.

## 🛠️ Getting Started

To use these skills, ensure you are using the Kilo Code extension in VS Code. The skills are automatically discovered from the `.kilocode/skills/` directory.

### Example Usage

You can trigger specific skills by asking questions related to their domain. For example:
- "Create a generative art piece using `algorithmic-art`."
- "Help me build a financial model for my startup using `xlsx`."
- "Write a technical spec using the `doc-coauthoring` workflow."
